Generated API reference

Run native-api-bindgen docs in your project: it writes generated-docs/, one page per generated type with the native symbol, the generated symbol, availability, threading, permissions, reason codes and a link to the official reference. It contains metadata only — no SDK documentation is copied — and stays local by default because it is derived from the SDK on your machine.

Commands

native-api-bindgen doctor        # SDKs and toolchains found
native-api-bindgen generate ...  # android | flutter | ios | react-native
native-api-bindgen update        # regenerate configured targets
native-api-bindgen coverage      # generated vs. discovered, with reasons
native-api-bindgen why-skipped   # why a symbol was not generated
native-api-bindgen docs          # generated-docs/ (local API reference)
native-api-bindgen audit-license # check inputs and outputs for licensing issues
